Java Library & CLI Tool (IPv4 / IPv6 WHOIS Resolver)

複数のIPアドレスをWHOIS検索し、CIDR単位で集約

ip2cidr は、大量のIPv4 / IPv6アドレスを入力として受け取り、OSの whois コマンドからCIDRブロック・国コード・登録組織・管理者/技術/Abuse連絡先を自動抽出して整理するJavaライブラリおよびCLIツールです。

クイックスタートを見る 対話型コマンドビルダーを試す GitHub リポジトリ
  • 同一CIDRへの自動名寄せ・集約
  • IP昇順ソート＆直前CIDR判定でWHOISを節約
  • 5秒間隔 / ヒット時0.5秒 / 制限時60秒×10回リトライ
  • ARIN / APNIC / RIPE / LACNIC / AFRINIC / JPNIC 対応

主な特徴と解決アルゴリズム

WHOISサーバーへの負荷とレートリミットを抑えながら、複数のIPアドレスを最小限のクエリ数で正確にCIDRへマッピングします。

  • 01

    同一CIDRの自動集約

    複数の入力IPアドレスが同じCIDRブロックに属する場合、1つの WhoisCidrInfo インスタンスに統合し、該当した入力IP一覧（Matched IPs）を保持します。

  • 02

    昇順ソート＋直前CIDR即時判定

    入力されたIP群を最初に数値昇順でソートします。直前に解決したCIDR範囲に次のIPが含まれるかを即座にチェックし、whois 実行をスキップしてキャッシュを再利用します。

  • 03

    堅牢なレートリミット制御

    新規検索時はデフォルト5秒間隔、キャッシュヒット時も0.5秒待機してバーストを防止。万一レートリミット応答を受けた場合は60秒待機×最大10回まで自動リトライします。

  • 04

    世界中のRIR・JPNICフォーマット対応

    ARIN / APNIC / RIPE / LACNIC / AFRINIC / JPNIC に対応。明示的な CIDR: 行がない場合でも inetnum や NetRange のIP範囲からCIDRを自動算出します。IPアドレス帯域が中途半端になる場合は、その帯域を過不足なく複数のCIDRブロックに分解して保持・判定します。

  1. STEP 1

    IPアドレスの数値昇順ソート

    IPv4 / IPv6アドレスを解析し、近接するIPアドレスが連続して処理されるように数値昇順で並び替えます。

  2. STEP 2

    直前CIDR・キャッシュ照合

    直前に解決したCIDRブロック（複数CIDRへ分解された全ブロックおよび既知キャッシュ）に包含されるか判定。ヒット時は0.5秒待機のみでWHOISをスキップします。

  3. STEP 3

    WHOIS実行＆CIDR分解・リトライ

    未解決IPのみ5秒間隔で whois を実行（制限時は60秒待機×最大10回リトライ）。IPアドレス帯域が中途半端な場合は複数のCIDRに分解して算出します。

  4. STEP 4

    出力整形（CIDR単位 / IP単位）

    標準出力またはUTF-8 CSVファイル（数式インジェクション対策済み）へCIDR単位またはIP単位で出力します。

中途半端なIPアドレス帯域のCIDR分解アルゴリズム

WHOISの inetnum や NetRange で示される開始IP〜終了IPの帯域が単一のCIDR境界に収まらない中途半端な範囲（例: 192.0.2.10 - 192.0.2.25）になる場合、その帯域を過不足なく表現する最小数のCIDRブロック群（例: 192.0.2.10/31, 192.0.2.12/30, 192.0.2.16/29, 192.0.2.24/31）へ自動的に分解します。検索対象IPを包含するブロックを代表CIDR（CIDR）とし、分解された全CIDR（AllCIDRs）もキャッシュ保持するため、後続のIPが分解後のどのCIDRに含まれていても正確にWHOIS検索をスキップできます。

CSV出力フォーマット仕様

--csv <path> オプション（または CsvFormatter クラス）で出力されるCSVファイルのカラム構成とセキュリティ仕様です。

CIDR単位モード（デフォルト: -m cidr）

1行につき1つのCIDRブロックを出力します。同一CIDRに属する複数の入力IPは MatchedIPs カラムにセミコロン区切り（; ）で格納されます。

  1. CIDR — 代表CIDR（例: 8.8.8.0/24）
  2. NetworkIP — ネットワークアドレス（例: 8.8.8.0）
  3. PrefixLength — プレフィックス長（例: 24）
  4. AllCIDRs — 検出された全CIDR一覧（; 区切り）
  5. IPRange — IP範囲表記（例: 8.8.8.0 - 8.8.8.255）
  6. CIDR(inetnum) — 参考: 割り当て範囲（inetnum 等）由来のCIDR
  7. CIDR(route) — 参考: BGP経路情報（route 等）由来のCIDR
  8. IP Range(inetnum) — 参考: 割り当て範囲（inetnum 等）由来のIP範囲
  9. IP Range(route) — 参考: BGP経路情報（route 等）由来のIP範囲
  10. MatchedIPs — 該当した入力IP一覧（; 区切り）
  11. Country — 国コード（例: US, JP）
  12. Registrant — 登録組織名・登録者名
  13. NetName — ネットワーク名
  14. Descriptions — 説明・備考情報（ | 区切り）
  15. AdminContacts — 管理者連絡先（; 区切り）
  16. TechContacts — 技術連絡先（; 区切り）
  17. AbuseContacts — Abuse連絡先（; 区切り）
  18. RawWhoisOutput — 生のWHOIS出力（--raw 指定時のみ）

IP単位モード（-m ip / --ip）

1行につき1つの入力IPアドレスを出力します。元のIPリストと1対1で突合したい場合や、Excel / Google Sheets のVLOOKUP等で利用する場合に便利です。

  1. IPAddress — 入力されたIPアドレス（例: 8.8.8.4）
  2. CIDR — 所属する代表CIDR（例: 8.8.8.0/24）
  3. NetworkIP — ネットワークアドレス（例: 8.8.8.0）
  4. PrefixLength — プレフィックス長（例: 24）
  5. AllCIDRs — 検出された全CIDR一覧（; 区切り）
  6. IPRange — IP範囲表記（例: 8.8.8.0 - 8.8.8.255）
  7. CIDR(inetnum) — 参考: 割り当て範囲（inetnum 等）由来のCIDR
  8. CIDR(route) — 参考: BGP経路情報（route 等）由来のCIDR
  9. IP Range(inetnum) — 参考: 割り当て範囲（inetnum 等）由来のIP範囲
  10. IP Range(route) — 参考: BGP経路情報（route 等）由来のIP範囲
  11. Country — 国コード
  12. Registrant — 登録組織名・登録者名
  13. NetName — ネットワーク名
  14. Descriptions — 説明・備考情報（ | 区切り）
  15. AdminContacts — 管理者連絡先（; 区切り）
  16. TechContacts — 技術連絡先（; 区切り）
  17. AbuseContacts — Abuse連絡先（; 区切り）
  18. RawWhoisOutput — 生のWHOIS出力（--raw 指定時のみ）
CSVインジェクション（数式実行）防止機能

外部レジストリのWHOIS応答に由来するテキストが =, +, -, @ で始まる場合、ExcelやGoogleスプレッドシートで開いた際に数式として評価されるのを防ぐため、自動的に先頭へシングルクォート（'）を付与してダブルクォートでエスケープします。

Javaライブラリとしての組み込み・APIガイド

com.ip2cidr.IpToCidrResolver をアプリケーションから直接呼び出して、型安全なモデルクラス（WhoisCidrInfo, Cidr）として結果を取得できます。

1. 基本的な使い方（IpToCidrResolver）

Example.java 
import com.ip2cidr.IpToCidrResolver;
import com.ip2cidr.model.WhoisCidrInfo;
import java.util.List;

public class Example {
    public static void main(String[] args) {
        IpToCidrResolver resolver = new IpToCidrResolver();

        List<WhoisCidrInfo> results = resolver.resolve(
                "8.8.8.8",
                "8.8.8.4",   // 8.8.8.0/24 に含まれるため whois 検索をスキップして流用
                "1.1.1.1"    // 5秒待機後に whois 検索を実行
        );

        for (WhoisCidrInfo info : results) {
            System.out.println("CIDR       : " + info.getCidr());                   // 例: 8.8.8.0/24
            System.out.println("Network IP : " + info.getCidr().getIpAddress());    // 例: 8.8.8.0
            System.out.println("PrefixLen  : " + info.getCidr().getPrefixLength()); // 例: 24
            System.out.println("IP Range   : " + info.getIpRange());                // 例: 8.8.8.0 - 8.8.8.255
            System.out.println("Matched IPs: " + info.getMatchedIpAddresses());     // 例: [8.8.8.4, 8.8.8.8]
            System.out.println("Country    : " + info.getCountry());                // 例: US
            System.out.println("Registrant : " + info.getRegistrant());             // 例: Google LLC
            System.out.println("NetName    : " + info.getNetName());                // 例: GOGL
            System.out.println("Admin      : " + info.getAdminContacts());
            System.out.println("Tech       : " + info.getTechContacts());
            System.out.println("Abuse      : " + info.getAbuseContacts());
        }
    }
}

CustomResolverExample.java 
import com.ip2cidr.IpToCidrResolver;
import com.ip2cidr.model.WhoisCidrInfo;
import com.ip2cidr.util.CsvFormatter;
import com.ip2cidr.util.CsvFormatter.OutputMode;
import com.ip2cidr.whois.CommandWhoisExecutor;
import com.ip2cidr.whois.WhoisParser;

import java.nio.file.Path;
import java.time.Duration;
import java.util.List;

public class CustomResolverExample {
    public static void main(String[] args) throws Exception {
        IpToCidrResolver resolver = new IpToCidrResolver(
                new CommandWhoisExecutor(Duration.ofSeconds(30)), // コマンドタイムアウト: 30秒
                new WhoisParser(),
                Duration.ofSeconds(5),    // 通常whois検索間隔: 5秒
                Duration.ofMillis(500),   // キャッシュヒット時待機: 0.5秒
                Duration.ofMinutes(1),    // レートリミット検知時待機: 1分
                10,                       // 最大リトライ回数: 10回
                duration -> Thread.sleep(duration.toMillis())
        );

        List<WhoisCidrInfo> results = resolver.resolve(List.of("1.1.1.1", "8.8.8.8"));

        // CIDR単位のCSV文字列を取得
        String csvText = CsvFormatter.format(results, OutputMode.CIDR, false);

        // IP単位でCSVファイルに保存
        CsvFormatter.writeToFile(Path.of("output_ip.csv"), results, OutputMode.IP, false);
    }
}

3. WhoisCidrInfo メソッド一覧

WhoisCidrInfo 主なゲッターメソッド
メソッド 戻り値の型 説明
